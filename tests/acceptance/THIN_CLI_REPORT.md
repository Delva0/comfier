# Independent thin CLI acceptance

The corrected 0.3.0 implementation passes independent CPU acceptance. This report does not validate the withdrawn automatic installer, a new cloud deployment, GPU model execution, or a new performance claim.

The tested wheel is `comani-0.3.0-py3-none-any.whl`, SHA256 `bb117cd54002d794e90d0ce6d7dcf3d647efa18cf80f32339b8be1aeece6ed3a`. Production source was frozen against baseline commit `758738ee07e1d13223fde9013effd4fa6286f942`; all 17 package Python files and `pyproject.toml` match the implementer's v2 manifest. Independently installed copies in the runtime, existing wheel gate, and a newly created SDK-only venv match every package file hash. All import from their own `site-packages`; the two SDK environments have no Torch.

The final wheel's standard non-GPU suite passed **113 tests, with 2 GPU tests deselected**, in 76.08 seconds. After script retirement, collection still finds 115 tests; `ruff check src tests scripts examples` passes. The full suite was not repeated because cleanup did not change frozen production source.

Independent regression found a real startup bug: native allocator auto-detection mutates `args.cuda_malloc`, so a later default runtime was incorrectly treated as requesting new device settings. The first wheel (`05b8e76b4e16d85fa8fb70180ec56bf656cb66bfffc77a55807f52c3bd9d557d`) produced 21 failures and 15 setup errors with the same cause. The implementer changed only the explicit-option guard in `startup.py`; the corrected wheel passes three sequential default runtimes with real eager calls, the affected fresh device/API checks, HTTP/metadata probes, and the full standard suite. Earlier independent cache/path/SDK checks remain evidence for unchanged components; the final standard suite also reruns all three cache modes.

Raw logs, probes, both wheel identities, installed hashes, and JSON observations are retained in `.local/thin-cli-acceptance/`. The first failure is preserved under `before-allocator-fix/`. All test-created daemon process groups were stopped. Shared Comfy source, its environment and original model files were not modified; no cloud instance or model download was used.
